## Instructions for the Note-Taker

This sheet is completed during the session, one sheet per participant. Fill in every cell in real time — do not reconstruct from memory after the session ends.

**Success (NAV-01):** Mark **SI** if the participant reached the defined end state for the task without requesting help from the moderator. Mark **NO** if the participant requested help, was given a directional hint, or abandoned the task before completing it. There is no partial credit — the outcome is binary.

**Time (NAV-02):** Start the stopwatch when the task card is handed to the participant. Stop it when they reach the defined end state, request help, or explicitly abandon. Record in **mm:ss** format. If the task was not completed, still record the elapsed time at the moment it ended.

**Do not stop the stopwatch** during think-aloud pauses, hesitations, or neutral moderator prompts. Time runs continuously from task start to task end.
