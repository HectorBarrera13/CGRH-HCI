# AI prompt reflection: Designing usability test tasks

For our usability testing, we focused on navigability as our key attribute — specifically how intuitively users could move between the system's main sections: CFDI history, savings funds, and the admin and coordination panels. Rather than spending time manually designing a task set from scratch, we turned directly to an AI tool and crafted a prompt that included the system context (a web platform for UADY employees to access payroll and savings documents), the target users (university staff with varying technical backgrounds), and the specific attribute we wanted to evaluate. The AI returned a structured, coherent set of tasks in under a minute — tasks we then cross-checked against a couple of usability references to verify they were reasonable. Reflecting honestly on this: the prompt-based approach was dramatically faster than a team-designed process would have been, where we would have needed to align on scope, debate task wording, and iterate through review cycles. However, speed comes with a trade-off — the AI had no knowledge of our actual interface, our users' real context, or the edge cases we discovered during development, so the tasks were generic and required some judgment to validate.

My take is that AI works best as a first-draft accelerator when time is short, the team has domain knowledge to filter the output, and the attribute being tested is well-defined enough to prompt precisely. Manual design, on the other hand, earns its cost when the system is highly specialized, the user population is narrow or atypical, or when the team needs the design process itself to build shared understanding of what they're testing and why.

Prompt used: "We are building a web system for UADY university employees that allows them to view and download their CFDI (payroll receipts in PDF, XML, or ZIP), savings fund documents, housing fund documents, and a box savings section — all organized as historical tables with tabs. There is also an admin panel for uploading files and a coordination panel for managing employee roles. The usability attribute we want to evaluate is navigability. What tasks should we ask users to perform during a usability test to collect data on this attribute? Please provide a specific, actionable task list."
