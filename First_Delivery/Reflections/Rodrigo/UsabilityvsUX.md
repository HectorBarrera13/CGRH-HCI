### Usability vs UX
Usability and UX are strongly connected to HCI, this las one concept is the scientific basis where Usability and UX lives, usability means the facility where de user can interact with the system and UX focuses on user's satisfaction. We can respond by planting question: Usability responds to how easy it is to perform a task and UX responds how an user felt doing it.

In the CGRH project I can relate this difference by downloading a CFDI, both terms are strongly related, but Usability can be determined by counting the steps required for a download, and UX can be determined by user's emotional opinion doing it, like if this user was stressed or felt confident because it was too easy.

An example for the project would be an instant document validation, in few words we could improves the experience by confirming in real time whether the format and readability are suitable before sending just like LinkeId by simply asking the user if they felt they sent the document correctly, it reduces employee anxiety and prevents the cycle of rejection and frustration days later, generating users trust.
