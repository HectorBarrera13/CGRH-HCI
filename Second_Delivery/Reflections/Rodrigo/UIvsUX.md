# UIvsUX

---

With the provided link sent to us, I read an interesting fact about UX/UI: UI is about the product, UX is about the user. Last block we learned as a team that UI is focused on what is seen and interacted with, UX is focused on how user felt by interacting with this UI.

From an analogical point of view, UI is like a map because is a physical product guide to help the user to reach a destiny, UX is the trip because multiple users can reach the same destiny in different forms, but user picks which route could be better for them.

In our CGRH project, we can differentiate UI because it refers to the use of a color palette and the use of representative icons for Files, Payroll, Reports, it focuses on the visual presentation and how the elements are positioned on the screen so that the user can quickly identify this tools. UX includes a confirmation message to prevent accidental situations because it focuses on the user's mental state to avoid human errors and reducing anxiety when handling things.
