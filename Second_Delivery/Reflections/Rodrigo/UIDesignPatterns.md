# UIDesignPatterns

---

A design pattern isn't just how a component looks, instead that is focused on how this component reacts when different users interact with. While I was looking for more details about design patterns, which i haven't any idea that this thing was really used in the world of work, I found consistency about part of universal usability in the technical aspects of the software, so I want to argue that Patterns are like a container of good practices.

For a practice to be considered good, it must be demonstrated that these techniques are effective, so I found that World Wide Web Consortium, better called W3C, through its Web Accessibility Initiative or WAI, it has standardized the patterns so that they are understandable by assistive technologies such as screen readers for people with visual impairments.

That can be used in our CGRH project, where, in the Aria Data Grid pattern, the W3C says that a retired person or a person who has difficulty seeing can navigate using only the keyboard, I don't know if it's implemented, but it should be.
