# UI vs UX
UI and UX are two terms that are constantly used together to the point where  people treat them as the same thing or one single being a lot of the time. The article makes the distinction clear. UI refers to the physical and technical elements that allow the user to interact with the product, while UX is about the "cultivation of satisfaction and loyalty through the usability and positive emotional response a user experiences", as it is defined the article. In short, I see it in that one is what you see on the screen, the other is how the whole interaction makes you feel, the keyword being Experience.

In our project, a good example of UI is the payroll records table: the layout of the fields, where the download buttons sit or where the filters are located. These are visual interactive elements you can point at on the screen. A UX example would be the bulk download functionality for these records, where we had to make sure an employee could select multiple receipts to download at a time, because we identified that multiple file downloading was a regular ocurrence for this type of document. That involved understanding how the user thinks and what they need, not just how things look.

**UI is a step to achieving better user experience. You can have a visually clean and appealing interface and still deliver a frustrating experience if the flow does not make sense or the items are difficult to navigate, and I think that is the key takeaway from this distinction.**
