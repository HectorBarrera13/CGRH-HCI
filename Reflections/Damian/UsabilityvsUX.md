## Usability vs UX

HCI, Usability and UX are related in the next way, HCI is the area that investigates how are the humans and the computers interact among themselves, includes design, ergonomics, evaluation and technology. HCI have a measurable attribute, the usability, is defined as the degree to which a product can be used by specific users to reach specific objectives with effectiveness, efficiency and satisfaction. Then we have the UX, is more extended than the usability and is also part of the HCI, it is about all the perceptions and answers of a person before, during and after to use a product, including emotions, meaning, value and life context.

The difference between Usability and UX is that the usability focusses on if the user can complete the task, UX focusses on how does the user feels during and after complete the task. For example, let see the project, in the login, the usability would measure if the user completed the login without help, how much time did they need, how many failed tries they had; in this case the UX would measure if the user feel save typing the password, if the user had fear of commit an irreversible mistake or if at the end the user have the feeling of "maybe something wrong happened". So, the user could completed successfully the login (the usability is good), but that doesn't mean that the user is not insecure about the process, is responsible of the UX that the user don't feel like this.

An UX feature for my team's project could be feedback of the progress, it could be visual confirmations that communicate the user in every step that he is doing well, it could be checkmarks and positive messages. For example, when the user is creating his account, at the end show him some message like "Well done, your account was successfully created", emphasizing the "WELL DONE", in addition the message could be presented in color green or there could be a checkmark in the same color that represents the action was successfully completed; with this implementation the new user feels more secure because the web is saying him that he is going for a good path.
