# Are Nielsen´s heuristic still valid today?

The Nielsen´s 10 usability principles are still valid today, I can not think about a web page without these principles, it would be low understandable and hard to use. The page needs to provide the user the best experience, and the interface tell him what is he doing, and how to do what he wants to do, even if that is his first time in that website.

As we said in class, maybe these principles could need be more specific about how implement them, but that doesn't mean that they are not a good base in the development of friendly interfaces, maybe they just need to be standardized and don't let every page try to understand them and apply them wildly.

As I said, I can't think about a web page without these principles, in these times we can see in the biggest web sites this heuristic applicated, that supports the point that we still need them, you can check websites like Facebook, Netflix, Youtube, Amazon, Moodel, even the Chat GPT webpage have them.
